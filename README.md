# Setup Events · Brand & Feed

Materiale per ripensare da zero brand identity e feed Instagram di Setup Events.

## Dove caricare cosa

| Cartella | Cosa metterci |
|---|---|
| `01-reference/feed` | Screenshot dei profili Instagram che ti piacciono (feed interi e singoli post) |
| `01-reference/font-e-grafica` | Font, palette, impaginazioni, poster o siti che vuoi come riferimento |
| `02-logo` | Logo Setup Events in tutte le versioni (SVG o PNG trasparente) e loghi dei clienti |
| `03-foto-video` | Foto e fotogrammi dei video degli eventi, alla massima risoluzione |
| `04-materiale-clienti` | Materiale fornito dai clienti (brand book, linee guida) |
| `05-output` | Qui metto io le proposte: brand identity, palette, font, griglia del feed, copertine |

## Video grandi (oltre 25 MB)

Dal sito di GitHub i file normali arrivano a 25 MB. I video vanno nelle **Releases**, che accettano file fino a 2 GB:

1. Apri https://github.com/gabriellleshi1-png/setup-events-brand/releases/new
2. Tag: `video-01` (poi `video-02`, `video-03`…) → "Create new tag"
3. Trascina i video nel riquadro "Attach binaries"
4. Aspetta la fine del caricamento e premi **Publish release**
